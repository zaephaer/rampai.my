# rampai.my

A landing page platform to **showcase projects created using AI**. Visitors browse a
gallery of project cards (thumbnail + text) and click through to view each project
built with AI tools.

## Structure

```
rampai.my/
├── index.html            # The landing page
├── css/
│   └── style.css         # Styles
├── js/
│   └── script.js         # Interactions (filters, etc.)
├── assets/
│   ├── images/           # Logo, hero, general images
│   └── thumbnails/       # Project card thumbnails
└── README.md
```

## Running locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000
